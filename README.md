# DOCX & XLSX Professional Editor

تطبيق مكتبي متكامل ومهني لمعالجة وتحرير المستندات النصية وجداول البيانات التفاعلية (Word/Excel/PDF/Images) مع دعم التخزين المحلي، التصدير المتقدم، وبناء الحزم (APK) عبر Capacitor.

---

## 🌟 الميزات الرئيسية (Key Features)

1. **معالجة المستندات وجداول البيانات الشاملة:**
   - دعم كامل لتحرير ملفات Word و DOCX و DOC و Excel و XLS و XLSX.
   - دعم استعراض وتصدير مستندات PDF والصور (JPG, PNG).

2. **التخزين المحلي وإدارة الملفات:**
   - تحديد وإنشاء مجلدات الحفظ المخصصة في تخزين الجهاز المحلي.
   - قراءة وكتابة المستندات مباشرة في ذاكرة التخزين المحلي للجهاز.
   - حفظ وحمل المستندات بسهولة مع إدارة حالة الملفات.

3. **تبويبات شريط الأدوات العلوي:**
   - **تصميم (Design):** تخصيص الأنماط، الألوان، الخطوط، والخلفيات.
   - **تخطيط الصفحة (Page Layout):** إعداد الهوامش، حجم الورق (A4, Letter, Legal, etc.)، اتجاه الصفحة، وفواصل الصفحات.

4. **فواصل الصفحات الذكية:**
   - مسافة فاصلة دقيقة ومحددة بـ **(1.0 cm)** تماماً خارج أبعاد صفحات المستند.
   - فواصل نظيفة خالية من النصوص أو العناوين المزعجة لتجربة طباعة وعرض احترافية.

5. **خيارات التصدير والطباعة والمعاينة:**
   - تصدير بصيغ متعددة (PDF, Word, Excel, صور).
   - معاينة واقعية قبل الطباعة والتصدير.
   - لوحة مفاتيح عربية مخصصة للتشكيل والأحرف الخاصة.

6. **تصدير وبناء تطبيق Android (APK):**
   - مدعوم بواسطة Capacitor لبناء وتصدير حزمة التطبيق بصيغة APK للتشغيل على الأجهزة المحمولة.

## 🚀 التثبيت والتشغيل المحلي (Getting Started)

تثبيت الحزم:
\`\`\`bash
npm install
\`\`\`

تشغيل خادم التطوير:
\`\`\`bash
npm run dev
\`\`\`

بناء التطبيق للإنتاج:
\`\`\`bash
npm run build
\`\`\`
